# BL-WEB-003：任务生命周期自适应轮询

## 背景

Web 当前固定每 1.5 秒请求，与 `tmux-trigger` 的 15–30 秒轮询周期及 Agent 任务节奏不一致。参考诊断：P95 首包 20.4 秒、轮次聚合延迟 124440 秒、30823 个步骤等待聚合。

## 需求

- terminal 刷新与任务完成判定解耦。
- 任务判定采用 15–30 秒自适应退避；有有效输出或用户操作时收紧，无增量时放慢。
- 隐藏 tab 降频或暂停，切换时不产生并发轮询尖峰。
- 聚合积压独立呈现，不能靠提高前端轮询频率掩盖。
- 不使用轮询次数或短暂静默推断任务结束。

## 参考阈值

- P95 首包 10–30 秒 warning，≥30 秒 critical。
- P95 总耗时 30–60 秒 warning，≥60 秒 critical。
- 任意零首包或 600 秒级请求为 critical。
- HTTP 错误率 1%–5% warning，≥5% critical。
- 30 分钟诊断窗口；状态优先级 `critical > warning > unknown > healthy`。
