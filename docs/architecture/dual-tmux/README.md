# dual-tmux 架构图工件

- `dual-tmux-architecture.html`：可交互架构图。
- `dual-tmux-architecture.archify.json`：Archify 源规格。
- `dual-tmux-architecture.visual-check.html`：自动浏览器检查汇总。
- `dual-tmux-architecture.visual-check.json`：视口、可读性和容纳检查回执。
- `dual-tmux-architecture.visual-check.*.png`：深浅主题的视觉证据。

机制说明位于 [`../../mechanism-overview.md`](../../mechanism-overview.md)。

交付时的 Archify showcase 确定性检查为 9/9，组合检查 0 错误、0 警告。1920×1080 和 2048×1320 视口完整容纳；1440×900 和 1600×1000 存在少量纵向页面滚动，不影响图内容可读性。
